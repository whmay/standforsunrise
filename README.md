# Stand for Sunrise

Community advocacy website for standforsunrise.org.

## GitHub Pages
1. Settings → Pages → Deploy from a branch → main → /(root) → Save.
2. Set the custom domain to standforsunrise.org.
3. At your domain registrar, add GitHub Pages apex A records per GitHub documentation and optionally a www CNAME to whmay.github.io.
4. After DNS propagation, enable Enforce HTTPS.

## Before launch
- The hello@standforsunrise.org contact email is not configured.
- Confirm community organizers approve the language about fundraising.
- Do not collect donations until the fund, financial controls, and terms are ready.

This is an independent community site, not an official PTA or district website.
