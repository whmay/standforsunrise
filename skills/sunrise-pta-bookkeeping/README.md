# Sunrise PTA Monthly Bookkeeping Skill

Reusable, **instruction-only** workflow for Sunrise PTA monthly transaction review and reconciliation.

## Instructions

Read [SKILL.md](SKILL.md) before processing a month. Supply the month's statements, MoneyMinder records, processor CSVs, receipts and approved prior-month templates **in the working conversation**, not in GitHub.

The skill covers statement-order matching, protecting already-entered yellow rows, reviewing red rows, Stripe transaction-level breakdowns by program/contact, Givebacks/Benevity/Blackbaud checks, account reconciliation and report preparation.

## Privacy

**This repository is public.** No bank statements, MoneyMinder workbooks, payment exports, screenshots, donor/student records, account identifiers, or real monthly financial data belong in this folder. Its files contain only generic instructions.

This skill is a repository reference, **not automatically installed as a ChatGPT skill**.
